本地运行的论文研究与写作工作台，计划在 GitHub 开源。需求依据见 outputs/ 目录下的《01-论文工作台-产品与技术方案.md》与《02-论文工作台-AI开发交接提示词.md》。

## 当前进度

### 已实现（阶段 1）

- 创建项目：学科多选 + 研究方法选择 + 已有材料入口（题目/文献/数据/初稿，可稍后补充）
- 13 个论文阶段导航；状态流转：未开始 / 进行中 / 待确认 / 已完成 / 已跳过（可恢复，记录原因）
- 三种研究方法模板（化学与材料实验 / AI 算法 / 问卷定量）：同一阶段按方法展示不同输入与记录结构；其余方法明确标注「模板待补充」
- 阶段工作区统一结构：目标 / 需要什么材料 / 你要做什么 / 会得到什么 / 检查清单 / 下一步 + 模板字段 + 自动保存
- 本地 SQLite 持久化（Electron 内置 node:sqlite，无原生模块），关闭重开内容恢复
- 带材料进入：自动建议起始阶段，中间阶段标记「已有材料」，项目首页展示材料缺口提示

### 已实现（阶段 2）

- 服务与模型设置：主流服务商预设 + 自定义 OpenAI 兼容中转 / Anthropic 风格
- API Key 经系统安全加密（safeStorage）存储，只存密文；界面与日志中不出现明文
- 网络方式：直连 / 跟随系统代理 / 自定义代理
- 三层连接测试：鉴权 → 模型可用 → 实际能力，支持取消
- 五个任务角色（检索辅助 / 研究设计 / 写作 / 分析解释 / 审阅）分别分配服务商与模型

## 运行与验证

```bash
npm install          # 网络受限时可先设置 ELECTRON_MIRROR=https://npmmirror.com/mirrors/electron/
npm run dev          # 开发模式（vite + electron）
npm test             # 单元测试（19 个用例）
npm run test:electron # 桌面端到端测试（3 个用例：主流程 + 三类模板 + 模型配置三层连接测试；使用独立临时 userData，不读写日常数据）
npm run desktop:pack # 打包为解包目录（release/win-unpacked）
```

验证证据：单元测试 19/19；electron 端到端 3/3（含模拟 OpenAI 兼容服务的 401 鉴权失败与取消场景）；win-unpacked 打包应用实测可启动并创建数据库。真实 API Key 的联网验证需用户提供 Key 后执行。
